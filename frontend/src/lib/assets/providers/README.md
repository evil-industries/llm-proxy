# Provider marks

Monochrome SVGs from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/82e641b4fece9d1028a127149af9ded00df5ac0c/packages/static-svg/icons), pinned to commit `82e641b4fece9d1028a127149af9ded00df5ac0c`. The upstream MIT license is included in [LICENSE](./LICENSE). Brand marks belong to their respective owners.

Assets are bundled locally and rendered as CSS masks using the surrounding text color. Provider names remain visible alongside the decorative marks. Unknown providers use a generic network icon.
